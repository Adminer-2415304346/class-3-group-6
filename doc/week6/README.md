## 覆盖与口径

10个用例统一编号为UC01—UC10：文章列表、文章详情、搜索、注册激活、登录退出、找回密码、评论回复、表情互动、第三方登录绑定、后台管理。10个用例均有说明和顺序图，共135条分析级交互消息。

DFD含14条外部流，顶层与一层保持平衡；一层含45条数据流，按四个处理分区显示。重复实体/存储使用同一编号，不表示数据复制或增加了下一层。字典另含35个数据结构、44个关键数据元素、7个数据存储。

系统有评论审核和单篇关闭评论功能；全站入口控制、文章详情发布状态、父评论归属、注册结果页路由、验证码及批量更新等现存边界已在报告中如实记录。本周不修改这些业务规则。

本轮仅在 `src/DjangoBlog/blog/views.py` 增加3组共6行SZX注释，解释详情查询边界、分类筛选差异及浏览量插件调用。原成员贡献与前两周材料保留。

本地未提供TSPi教材正文，学习辅助依据出版社目录确认章节主题，不冒充教材逐章原文摘要或本人已完成阅读。实际阅读、组会日期、成员确认与发言需由本人/小组据实补充；资料编制不替代这些活动。

## 重新生成与检查

在仓库根目录，用安装了 `python-docx`、`Pillow` 的Python运行：

```powershell
$env:PYTHONUTF8 = '1'
python .\doc\week6\tools\build_report.py
powershell -NoProfile -File .\doc\week6\tools\export_pdf.ps1
python .\doc\week6\tools\verify_delivery.py
git diff --check
```

`export_pdf.ps1` 使用本机Microsoft Word COM，打开生成的Word只读导出。PDF内容检查另需PyMuPDF。静态生成/检查脚本不导入Django，也不读取业务数据库或第三方凭据。脚本里的Windows字体路径可按本机字体安装情况替换。
