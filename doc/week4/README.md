# 第四周交付物

本目录使用课程提供的《软件界面设计说明书模板》和《软件数据模型设计说明书模板》编制，内容主题为“AI Agent 工程实践”。

| 文件 | 用途 |
| --- | --- |
| `AI Agent工程实践-软件界面设计说明书.docx` | 第四周提交版：功能、实际界面截图、思维导图、流程与模板包图 |
| `AI Agent工程实践-软件数据模型设计说明书.docx` | 历史初稿留存；第五周正式说明书见 `../week5/` |
| `第四周计划与组会记录.md` | 2026 年 9 月 30 日线上组会纪要、工作计划与会后交付材料 |
| `assets/` | 本地运行截图与图示原图，便于复查和后续修改 |
| `tools/` | 截图、图示和文档生成脚本 |

界面设计说明书已依据仓库根目录的六人名单补齐组号、成员与审核人；本目录的数据模型说明书为历史初稿，不再作为第五周提交版本。第五周正式说明书、组会记录和生成工具见 [第五周交付物](../week5/README.md)。界面截图来自独立的本地演示数据库 `class3group6_agent_week4`，不会将数据库凭据提交到仓库。该数据库仅存在于编制者电脑上；其他成员可按项目 README 创建自己的 MySQL 数据库，执行 `migrate`、`create_testdata`，搜索演示还需执行 `update_index`。

文档脚本默认从仓库上一级目录读取老师给的两份模板。若模板位置不同，请修改 `tools/build_documents.py` 中的模板路径。生成脚本依赖 `python-docx` 和 Pillow，截图脚本依赖 Playwright 和可用的 Chromium/Chrome。DOCX 已由 Microsoft Word 导出 PDF 做过版式检查；临时 PDF 不属于交付文件。
