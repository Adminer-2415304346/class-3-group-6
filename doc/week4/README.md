# 第四周交付物

本目录使用课程提供的《软件界面设计说明书模板》和《软件数据模型设计说明书模板》编制，内容主题为“AI Agent 工程实践”。

| 文件 | 用途 |
| --- | --- |
| `AI Agent工程实践-软件界面设计说明书.docx` | 功能、实际界面截图、思维导图、流程与模板包图 |
| `AI Agent工程实践-软件数据模型设计说明书.docx` | 数据需求、ER 图、字段类型、约束及模型职责 |
| `第四周计划与组会记录.md` | 组会议程和计划初稿；会议事实待小组填写 |
| `assets/` | 本地运行截图与图示原图，便于复查和后续修改 |
| `tools/` | 截图、图示和文档生成脚本 |

两份 DOCX 内的学号、成员及审核信息故意标记为“待小组填写”，没有编造组会结论。截图来自独立的本地演示数据库 `class3group6_agent_week4`，不会将数据库凭据提交到仓库。该数据库仅存在于编制者电脑上；其他成员可按项目 README 创建自己的 MySQL 数据库，执行 `migrate`、`create_testdata`，搜索演示还需执行 `update_index`。

文档脚本默认从仓库上一级目录读取老师给的两份模板。若模板位置不同，请修改 `tools/build_documents.py` 中的模板路径。生成脚本依赖 `python-docx` 和 Pillow，截图脚本依赖 Playwright 和可用的 Chromium/Chrome。DOCX 已由 Microsoft Word 导出 PDF 做过版式检查；临时 PDF 不属于交付文件。
