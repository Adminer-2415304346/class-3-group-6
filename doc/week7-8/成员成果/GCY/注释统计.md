## 三层注释示例

模块层（`settings.py` 文件头）：
```python
# GCY（模块层）：本项目共用层的全局配置入口。职责是把环境变量翻译为
# Django/Haystack/Compressor 的运行参数，决定：①检索后端（Whoosh 或
# Elasticsearch，见下方 HAYSTACK_CONNECTIONS 分支）；②缓存后端（默认
# LocMem，设置 DJANGO_REDIS_URL 后切换为 Redis）；③邮件后端与静态资源
# 压缩行为。输入主要是 os.environ，输出是一组模块级配置常量，被 urls、
# blog、accounts 等模块在 import 时读取。执行边界：本文件不发起任何
# 网络或数据库连接，只做配置装配。
```

类/函数层（`apps.py` ready()）：
```python
# GCY（类/函数层）：Django 应用就绪钩子，进程启动时由应用注册表
# 调用一次（含 manage.py、WSGI、测试 runner）。此处延迟导入插件
# 加载器以避免循环依赖（loader 依赖 settings），并保证在模型和
# URL 系统就绪后再注册插件钩子。若插件目录缺失或个别插件导入
# 失败，load_plugins 内部捕获异常，不会阻断应用启动。
```

关键逻辑层（`blog_signals.py` update_fields 判断）：
```python
# GCY（关键逻辑）：update_fields == {'views'} 表示本次保存只改了
# 浏览量（浏览计数接口用 update_fields 局部更新），此时无需清理
# 各类列表/详情缓存，提前返回可避免高频访问把缓存全部击穿。
# 限制：批量 QuerySet.update() 不触发 post_save 信号，因此批量
# 改动文章不会走这里的缓存清理，需另行在业务层处理。
```
