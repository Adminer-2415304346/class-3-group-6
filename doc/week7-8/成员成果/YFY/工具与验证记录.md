## 5. 隔离测试记录

### 5.1 隔离方式

驱动 `doc/week7-8/tools/run_isolated_tests.py` 在临时目录生成隔离 settings，并做以下覆盖：

- 数据库：SQLite 内存库（测试运行器使用内存库）。
- 缓存：`LocMemCache`。
- 邮件：`locmem.EmailBackend`，不投递真实邮件。
- 搜索：Haystack `SimpleEngine` + `BaseSignalProcessor`，移除 Elasticsearch 配置。
- 插件：从 `ACTIVE_PLUGINS` 移除 `cloudflare_cache`。
- 静态文件：使用普通 `StaticFilesStorage`，避免 manifest 缺失。
- 网络：替换 `socket.socket.connect` 与 `socket.create_connection`，出站连接直接抛 `ISOLATED_TEST_BLOCKED_NETWORK`。
- 线程：将 `_thread.start_new_thread` 改为同步调用，评论邮件线程同步执行。
- `DEBUG=False`、`TESTING=True`、关闭日志落盘。

实际命令：

```powershell
# 合并 develop 前（YFY 自建 runner）
python doc/week7-8/tools/run_isolated_tests.py `
  accounts.test_auth_hardening accounts.tests `
  accounts.test_user_business_logic accounts.test_admin

# 合并 develop 后（组内标准 runner，含 SZX 新增页面测试）
python doc/week7-8/tools/run_isolated_tests.py `
  accounts.test_auth_hardening accounts.tests `
  accounts.test_user_business_logic accounts.test_admin `
```
