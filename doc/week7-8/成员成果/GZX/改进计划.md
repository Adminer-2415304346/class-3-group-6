# GZX oauth 改进计划

## 一、本轮已完成

### 1. HTTP 请求显式超时（可靠性，已验证）
- 改动：oauthmanager.py 新增 `OAUTH_HTTP_TIMEOUT=10`，基类与 ProxyManagerMixin 的 `do_get/do_post` 四处统一传 `timeout=`。
- 解决：Bandit B113×4（请求无超时），平台无响应不再无限挂起。
- 验证：新增 2 个 mock 断言用例；隔离跑 `oauth.test_oauth_business_logic` 26 测试全过；after 复扫 B113=0。
- 剩余风险：超时值 10s 为经验值，慢网络/大头像场景可能偏短；Timeout 在上层多被 broad except 兜底，错误码未细化（见待办 P3）。

### 2. 三层 GZX 注释
- 8 个源码文件补模块/函数/代码块注释，纯注释不改行为；统计见《注释统计.md》。
