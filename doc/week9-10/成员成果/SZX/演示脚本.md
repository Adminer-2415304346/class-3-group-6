# SZX业务功能演示脚本

负责人：石兆翔；功能B91/B92。正式视频由组长在全组集成和验证后统一录制，以下为本模块可复现脚本，不是已经录制的视频。

## 1. 前置

使用GCY提供并验证的settings_demo启动，保留独立数据库和媒体目录；创建本地有效staff、普通用户及已发布演示文章。确认媒体URL可访问，准备PNG/JPEG/WEBP、一张带相机方向的JPEG、伪装PNG与超限样本。演示账号/文件为合成数据，不展示真实密码或密钥。

本轮已经在独立临时配置实际启动系统并通过HTTP/浏览器验证；当前工作会话的上传预览为http://127.0.0.1:52925/upload-image/，这是临时预览地址，不是固定部署地址或最终交付环境。

## 2. B91 浏览量

1. 展示已发布文章和初始浏览量，刷新两次，说明每次请求只增加一次；后台/数据库核对结果。
2. 展示两个先读到旧值的实例回归：修复前10→11，修复后10→12。讲解数据库F增量和读回普通整数，说明这不是多机压力测试。
3. 展示修改文章标题后浏览数不会被再次递增的回归结果。

## 3. B92 上传

1. 以有效staff登录后台，打开/upload-image/，说明文件/像素/格式限制。
2. 选PNG并上传，展示成功状态、图片链接和预览，打开媒体链接验证实际图片。JPEG/WebP同理。
3. 换普通用户/匿名说明被拒；缺CSRF的请求显示403。使用伪装PNG、超大小/超像素样本展示拒绝且无非法文件。
4. 展示相同原文件名分别上传不会覆盖；说明实际格式与服务器生成后缀/路径，不以文件名猜图片。
5. 用方向6的JPEG展示竖拍保持正确方向，说明先旋转再清除元数据。

## 4. 解说结尾素材

展示433项相关回归、相同31个旧问题验证及新增手机方向用例。告警按历史范围说明，不能声称全系统零风险。全组视频开头统一展示第6组及石兆翔、喻飞扬、王子扬、顾梓鑫、宋洋、郭曹钰姓名；组员交脚本/样本，由组长统一录制。
