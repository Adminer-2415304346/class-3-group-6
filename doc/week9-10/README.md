## 2. 先统一，再并行

1. 先同步本任务包，读取[共享配置与接口约定v1.1](共享配置与接口约定.md)。SZX统一共享设置、路由、信号、配置入口和接口变更。
2. GCY 提供独立本地运行配置，其余五个 App 按文件边界实施必做项并接入共享配置。
3. 第9周完成主要实现、本人回归与复现信息整理；第10周完成六App功能测试、共享联调、互查和维护报告素材。以上为任务阶段安排，不是已发生的会议结论。
4. 个人分支→develop，集成回归与本地功能验证通过后，由组长统一录制并做最终主分支提交。当前远程有main、没有master；课件指定master的命名由组长确认并统一处理，本轮准备阶段不变更最终交付分支。

## 3. 课程要求与本组安排

- 课程：开组会、制定新两周计划、总结上一阶段；优化/完善/新增功能，至少覆盖每个App功能测试；本地运行并录MP4，视频开头展示组号及姓名；交整体源码、模板对应的开源软件维护报告、MP4。
- 评分重点：功能点/优化数量及修改/新增代码行数；文档和视频规范、质量也计分。每人两个必做、一个选做是本组安排，不冒充老师硬性数量要求。
- 每App覆盖正常路径、无效输入、权限/状态边界及本轮改动；原390项相关回归作为上轮基线，新增本轮测试，不用扫描代替功能验证。
- 使用[维护素材模板](维护素材模板.md)，组员提交`实现说明.md`、`功能测试记录.md`、`代码变更统计.md`三份MD及原始证据。复现信息写入实现说明；组长汇总Word并准备统一录制脚本和MP4。Word宋体/Times New Roman、文字黑色；不打包。
